## 🏓 Ping-Pong Game (Pygame)
Увлекательная классическая игра в пинг-понг для двух игроков, созданная на языке Python с использованием библиотеки Pygame.
## 🎮 Игровой процесс
Два игрока управляют своими ракетками, чтобы отбивать мяч и не дать ему пролететь за свою платформу. Если мяч улетает за левую или правую границу экрана, объявляется победитель.
## ⌨️ Управление
Каждый игрок управляет своей платформой с помощью клавиатуры:

* Игрок слева (Левая ракетка):
* Вверх — клавиша W
   * Вниз — клавиша S
* Игрок справа (Правая ракетка):
* Вверх — клавиша Стрелка Вверх
   * Вниз — клавиша Стрелка Вниз

## 🛠️ Технические требования
Для запуска игры вам понадобятся:

* Python 3.x
* Библиотека Pygame

## 🚀 Как запустить проект

   1. Убедитесь, что у вас установлен Python. Если нет, скачайте его с [официального сайта](https://www.python.org/).
   2. Установите библиотеку Pygame, выполнив команду в терминале (командной строке):
   
   pip install pygame
   
   3. Скачайте файлы вашего кода, а также изображения racket.png (ракетка) и tenis_ball.png (мяч) в одну папку.
   4. Запустите игру:
   
   python main.py
   
   
(Примечание: убедитесь, что ваш главный файл с кодом называется main.py или переименуйте команду запуска в соответствии с вашим файлом).
## 🧩 Особенности кода
Проект написан с использованием объектно-ориентированного программирования (ООП):

* Класс GameSprite — базовый класс для всех игровых объектов (картинки, размеры и позиционирование).
* Класс Platform — отвечает за движение ракеток и ограничения их перемещения по экрану.
* Класс Ball — отвечает за скорость мяча, его полет и отскок от верхних/нижних границ окна.
